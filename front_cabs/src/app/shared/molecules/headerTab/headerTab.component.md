# Componente UiHeaderTabs

El **UiHeaderTabsComponent** es un componente reutilizable diseñado para mostrar un encabezado con título, descripción opcional y un botón de acción. Está optimizado para usarse en vistas con pestañas (tabs) o secciones que requieren una acción principal destacada.

## ¿Para qué sirve?

Este componente se utiliza para:

- Proporcionar encabezados consistentes en vistas con pestañas
- Mostrar títulos y descripciones informativas
- Incluir acciones principales visibles (como botones de agregar)
- Mantener coherencia visual en secciones administrativas
- Organizar información jerárquicamente en listados

## Características

- Título principal obligatorio
- Descripción opcional con control de visibilidad
- Botón de acción opcional con etiqueta personalizable
- Control de estilos mediante propiedades booleanas
- Eventos para manejar acciones del usuario
- Diseño adaptable a diferentes contextos
