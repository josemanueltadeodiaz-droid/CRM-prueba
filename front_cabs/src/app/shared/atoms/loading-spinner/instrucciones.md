# Componente UI-Avtar

El **LoadingSpinnerComponent** es un componente reutilizable que muestra un indicador visual de carga acompañado opcionalmente de un mensaje informativo.  
Se utiliza para mejorar la experiencia del usuario mientras se realizan procesos asincrónicos como peticiones HTTP, cargas de datos o inicialización de vistas.


# Instalación

```typescript

import { UiAvatarComponent } from './ruta/atomic/avatar/avatar.component';

@Component({
  selector: 'app-mi-componente',
  standalone: true,
  imports: [UiAvatarComponent],
  // ...
})
```

## Características

- 🔄 Animación de carga circular
- 📝 Mensaje personalizable
- 🧩 Componente standalone
- 🎨 Estilos simples y adaptables
- ♻️ Reutilizable en múltiples vistas
