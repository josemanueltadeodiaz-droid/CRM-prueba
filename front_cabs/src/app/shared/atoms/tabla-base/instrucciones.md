## Resumen de Componentes de Tabla

Este conjunto de componentes permite construir tablas reutilizables, ordenadas y fáciles de mantener, separando claramente la responsabilidad entre encabezados y celdas de contenido.

# 🧩 Componente TableHeaderCell

## Función:
Representa una celda de encabezado (th) dentro de una tabla.

**¿Para qué sirve?**
Se utiliza para mostrar los títulos de las columnas, definir el ancho de cada columna y controlar la alineación del texto, manteniendo una apariencia visual consistente.

**Características principales:**

- Muestra el texto del encabezado
- Permite definir el ancho de la columna
- Permite alinear el texto (izquierda, centro o derecha)
- Incluye estilos base para encabezados

# 🧩 Componente TableCell

## Función:
Representa una celda de datos (td) dentro de una tabla.

**¿Para qué sirve?**
Se utiliza para mostrar información de cada fila, ya sea como texto simple o como contenido personalizado mediante templates, lo que permite crear tablas dinámicas y flexibles.

**Características principales:**

- Muestra valores simples
- Soporta templates personalizados
- Recibe el objeto completo de la fila
- Permite controlar la alineación del contenido
